**Download:** `Slate-Player-Setup-1.2.0.exe` (installer, updates itself) or
`Slate-Player-1.2.0-portable.exe` (no install). Not code-signed — on first run
choose *More info → Run anyway* in the SmartScreen prompt. Installed 1.1.0
updates itself; 1.0.0 needs this installer once.

### New in 1.2

- **A filmstrip you can actually watch** (`T`). It no longer races past 30
  tiles a second while playing: the strip holds still, the middle tile plays
  live, and the pictures either side cross-fade in place. Four views:
  - **Frames** — every frame around the playhead; shows Time while playing and
    fades back to the frames around wherever you pause.
  - **Time** — one exact picture per interval, ½ s to 5 min apart (`Ctrl`+wheel
    or −/+).
  - **Shots** — one picture per shot: the cuts are found automatically in the
    background, so the strip changes exactly when the picture cuts.
  - **Whole** — the entire video across the strip.
- **Jump between shots** — `Shift`+`↓` / `Shift`+`↑` land on the first frame
  after the next / previous cut.
- **Everything in one menu** — the ☰ button (top left, or `F10`) lists every
  feature in labelled groups with its shortcut; the gear opens Settings.
  The side panel's tabs are labelled, the control bar is grouped, and in / out
  points have their own icons.
- **Strips and shot lists are remembered** per video, so a file you've opened
  before shows its filmstrip at once.
- **Frame decoding: Auto / GPU / CPU** (Settings → Frame engine). Playback
  always uses the GPU; Auto picks the faster decoder for stepping and scrubbing
  (all CPU cores for 4K H.264 on 8+ core machines), GPU keeps the processor
  idle. Video info shows which one is in use.
